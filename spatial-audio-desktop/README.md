# 3D 사운드 (PC / 노트북)

유튜브·게임·영화 등 PC 소리를 **헤드폰용 3D 입체 음향**으로 바꿔 줍니다.
안드로이드 앱의 "강력 3D 모드"와 같은 엔진(HRTF 머리 모델 + 가상의 방 + 잔향)을 씁니다.

```
모든 PC 소리 → [Windows 출력: CABLE Input] → CABLE Output → 3D 사운드 → 내 헤드폰
```

> 💡 **유튜브처럼 브라우저 소리만이라면 설치가 필요 없습니다**: 크롬·엣지에서
> [웹 앱](https://yuseunghogi-commits.github.io/game/) → **[다른 탭 소리]** → 유튜브 탭 선택 → '탭 오디오도 공유'.
> 게임 등 브라우저 밖 프로그램 소리는 아래처럼 이 앱 + VB-CABLE 로.

## 처음 한 번만 설정 (Windows)
1. 무료 가상 오디오 장치 **VB-CABLE** 설치: https://vb-audio.com/Cable/ → Download
   → 압축 풀고 `VBCABLE_Setup_x64.exe` 우클릭 → **관리자 권한으로 실행** → Install → 재부팅
2. 작업표시줄 🔊 → 출력 장치를 **CABLE Input** 으로 변경
3. `3DSound.exe` 실행 → 입력 **CABLE Output**, 출력 **내 헤드폰** → **▶ 시작**

끝낼 때는 🔊 출력 장치를 다시 헤드폰으로 바꾸면 원래대로 돌아옵니다.

## Mac
VB-CABLE 대신 무료 **BlackHole 2ch** 설치 → 시스템 설정 > 사운드 > 출력을 BlackHole 로 →
`java -jar 3DSound.jar` (Java 17 이상 필요) → 입력 BlackHole, 출력 헤드폰.

## 조절
- **3D 강도**: 원음 ↔ 3D 비율
- **좌우 넓이**: 가상 스피커 각도 ±30°~±80°, 높을수록 좌우가 또렷
- **방 울림 / 잔향**: 방 안에서 듣는 느낌
- **3D 효과 켜기** 체크를 끄면 원음과 바로 비교 가능

## 소리 끊김 방지 (v2.5~)
- 시작할 때 출력에 약 32ms 를 미리 채워 두고, 가상 케이블과 헤드폰의 시계 차이(특히 블루투스)를 아주 작은 속도 조절
  (최대 ±0.5%, 보통 0.05% 이하 — 들리지 않음)로 맞춥니다. 그래도 한 번 끊기면 다음부터 여유를 10ms 씩 늘립니다 (최대 85ms).
- 화면 아래 상태 줄에 **지연**과 **끊김 횟수**가 보입니다. 계속 끊기면 이 숫자를 알려 주세요.
- 그래도 끊기면: 블루투스 헤드폰은 노트북 Wi-Fi(2.4GHz)와 전파가 겹쳐 끊길 수 있습니다 → 5GHz Wi-Fi 쓰기 / 유선 연결로 비교.

## 자동 업데이트 (v2.0~)
- 켤 때 GitHub 최신 릴리스를 확인해서 새 버전이면 창 위에 알림 → **[지금 업데이트]**
- Windows 앱(3DSound.exe)은 새 zip 을 받아 → 앱을 닫고 → 파일을 바꿔 끼운 뒤 → 다시 켭니다 (설정 유지).
  앱 폴더가 쓰기 금지 위치(예: Program Files)면 실패하고, 다음에 켤 때 안내가 나옵니다 → 바탕화면 등에 풀어 쓰세요.
- Mac/Linux jar 는 릴리스 페이지를 엽니다. 맨 아래 **업데이트 확인** / **새 버전 자동 확인**.
