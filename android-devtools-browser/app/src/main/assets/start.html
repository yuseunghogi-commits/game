어떤 사이트에서든 개발자 도구를 여는 브라우저

사용법

  1. 위 주소창에 주소나 검색어를 입력합니다. localhost:5173, 192.168.0.10:3000처럼 로컬 주소는 http로 엽니다.
  2. 아래 파란 </> 버튼으로 개발자 도구를 열고 닫습니다. 페이지 구석의 톱니 버튼도 같은 역할입니다(끌어서 옮길 수 있음).

개발자 도구 탭

  • Console — 로그·오류 보기, 자바스크립트 실행
  • Elements — DOM 트리, 스타일, 요소 선택
  • Network — XHR·fetch 요청과 응답
  • Resources — localStorage, sessionStorage, 쿠키, 스크립트·스타일시트
  • Sources · Info · Snippets

메뉴(⋮)

  • 페이지마다 자동 준비 — 켜 두면 로딩 중에 찍힌 로그도 콘솔에 남습니다(기본 켬).
  • 데스크톱 사이트 — PC용 화면 요청
  • CSP 해제 (실험적) — 콘솔에 입력한 코드가 막히는 사이트용

PC 크롬으로 원격 디버깅

휴대폰의 USB 디버깅을 켜고 PC에 연결한 뒤, PC 크롬에서 chrome://inspect를 열면 이 앱의 페이지를 데스크톱 개발자 도구로 볼 수 있습니다.
