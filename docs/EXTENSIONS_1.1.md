# PLANETARY GRID — 확장 1.1 (MVP 이후 추가 기능)

기준 문서: `PLANETARY_GRID_Design_Baseline_1.0.md`, `PLANETARY_GRID_Decision_Record_S05-S21.md`.
원본 V0.4 기획서·검토서·V0.5 결정 패키지는 바꾸지 않았다. 이 문서는 구현하면서 정한 세부 규칙과 수치를 기록한다. 모든 수치는 [추후 밸런싱]이다.

## 1. 기획 결정과의 대응

| 기능 | 근거 | 구현 요지 |
|---|---|---|
| 계획 건설 | Q32 C "계획 건설과 일괄 처리", §12.5 "여러 건설 계획을 한 번에 승인" | 대기열(최대 30건). DI마다 맨 앞부터 `buildCheck`/`lineCheck`가 통과하면 승인, 막히면 멈추고 사유 표시. 자금은 미리 예약하지 않는다 |
| 모듈 확장 | Q47 B "제한적 모듈 확장", S-09 "모듈 추가 공사 = 본 시설 기간의 30%" | 시설당 2개. 정격 +50%, 비용 55%, 유지비 +40%, 공사 30%. 같은 부지·접속점을 쓰므로 토지 임대료·사업권 기본 수수료가 늘지 않는다 |
| 접속점 | S-08 (b) "지역 허브 + 변전점 + 접속점" | 수요 허브가 기본 접속점(80 MW)을 겸하고, 변전소마다 변전점이 생긴다. 새 시설은 여유 있는 첫 접속점에 붙는다. 시설 하나는 한 접속점에 들어가야 한다. 접속 시설이 있는 변전점은 매각·폐기 불가 |
| 핵분열 발전 | S-10 "원자력 계열은 MVP 제외 → 후속 확장" | 연구 `gen3`(발전 3단계, 1.2M CR, 30일)로 해금. S-10이 지적한 별도 규칙을 넣었다: 기동 지연 6시간, 최소 출력 80%, 램프 3%/DI, 폐기비 30%, 복구 기간 2배 |
| 긴급 경고 자동 일시정지 | S-21 "기본 켜짐, 긴급 등급만" | 긴급 등급 = 핵심 부하 정전(하루 1회), 대출 상환 실패·연체 진입, 사업권·임대 정지로 시설 정지, 구조조정·회생불능. 경보음 + 일시정지 + 화면 아래 알림. 설정에서 끌 수 있다 |
| 긴급 복구 | 복구 우선순위 (Baseline §24 사건) | 고장마다 한 번, 남은 기간 ×0.5, 비용 = 기본 복구비 × 0.6. 동시에 여러 고장이 나면 플레이어가 돈으로 순서를 정한다. 핵심 부하 지역 고장은 추천 우선순위 93 |
| 시설 실적 | Baseline §27 정보 표시 | 시설마다 일별 발전량·판매·계약 인도·수익·연료·유지비·가동 DI(30일)와 누적. 계약 인도분 수익은 계약 단가로 귀속해 보여 준다(현금은 계약 정산에서 발생) |
| 지도 크기 | Baseline 목표 규모 96 지역 | 12(표준 기록) · 24 · 48 · 96. 지역이 많으면 지역 수요 × max(0.35, √(12/n)). 12가 아니면 기록은 사용자 지정 규칙 |

넣지 않은 것: **AI 경쟁사(시장 M3)**. 확정 결정이 M4 가격 수용자 시장(플레이어가 가격을 움직이지 않음)이므로, 경쟁사가 가격에 영향을 주는 M3는 기획 변경이 필요하다.

## 2. 저장 형식

- 스키마 v4. 마이그레이션 v3 → v4: 기존 시설을 기본 접속점부터 채우고 넘치면 변전점에 붙인다. 모듈 0, 실적 빈 기록, 계획 빈 대기열, 지도 크기 = 기존 지역 수.
- 세이브 칸: 수동 3 + 자동 3 (가장 오래된 자동 칸을 덮어씀). gzip 압축 후 로컬 저장소에 보관. 파일 내보내기(`.pgsave` = JSON 원문)로 다른 PC에 옮길 수 있다.
- 이전 단일 세이브(`planetary-grid.save.1`)는 처음 실행할 때 수동 1번 칸으로 옮긴다.

스크립트 플레이어(태양광 위주, 연구·계약 포함) 360일 결과 — 사용 수수료 조정 후:

|---|---:|---|
| 완화 | 5.8× | 정상 |
| 표준 | 4.0× | 정상 |
| 도전 | 2.9× | 정상 |

조정 전 같은 플레이어: 완화 3.5×, 표준 1.0×(연체), 도전 0.1×(회생불능).

시설 단위 일 순이익(시장가 약 81 CR/MWh 지역, 연료·유지비만, 30일 평균): 열발전 중형 24.9k, 풍력 중형 12.4k, 태양광 중형 4.7k, 핵분열 중형 116.6k CR. 저장시설은 기본 기준 가격에서 차익이 거의 없어 단독 수익은 음수다 — 계약 신뢰도용이며, 기준 가격 조정·자동 조정 연구로 개선한다(추후 밸런싱 과제).

## 4. 화면

- 시설 상세: 시설 이름이나 행성 위 시설 모형을 누르면 열린다. 일별 발전량·손익 막대, 가동률·이용률, 30일·누적 손익, 모듈 확장, 긴급 복구, 토지·매각·폐기.
- 행성 위 시설 모형: 유형별 저폴리 모형(열발전 냉각탑, 핵분열 돔, 태양광 패널, 회전하는 풍력 날개, 배터리 컨테이너, 변전 철탑). 건설 중 = 골조, 정지 = 어둡게, 고장·전조 = 머리 위 표시등.
- 튜토리얼 8단계: 상태로 완료를 판정하고 대상 버튼을 강조한다. 건너뛰기·다시 보기 가능.
- 설정: 음량 3종, 그래픽 품질(낮음: 텍스처 1024·구름 없음), 언어, 긴급 자동 일시정지, 자동 저장 간격.
- 영어 표시(beta): 화면 HTML을 사전·패턴으로 바꾼다. 지역 이름은 로마자로 표기한다.
