## 🎧 3D 사운드 — 유튜브·게임 소리를 헤드폰용 3D 입체 음향으로

아래 **Assets** 에서 기기에 맞는 파일을 받으세요.

| 파일 | 기기 |
|---|---|
| **3DSound-Android.apk** | 안드로이드 폰 (Android 8 이상, 강력 3D 모드는 10 이상) |
| **3DSound-Windows.zip** | Windows 노트북/PC (Java 포함, 설치 불필요) |
| 3DSound-Mac-Linux.jar | Mac / Linux (Java 17 이상 필요) |

> ℹ️ **Shizuku**(폰)와 **VB-CABLE**(PC)는 다른 회사 프로그램이라 여기 포함되지 않습니다. 처음 한 번만 아래 링크에서 설치하세요.
> - Shizuku: [Play 스토어](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api)
> - VB-CABLE: [vb-audio.com/Cable](https://vb-audio.com/Cable/)

### 📱 안드로이드
1. APK 설치 (이전 버전이 있으면 덮어쓰기 — 안 되면 지우고 설치)
2. 앱 → **🔑 강력 모드 권한 설정** → 안내대로 Shizuku 로 권한 받기 (처음 1번)
3. **강력 3D 모드** 선택 → **3D 음향 켜기** → 소리 공유 창에서 **시작**

### 💻 Windows
1. 무료 [VB-CABLE](https://vb-audio.com/Cable/) 설치 (관리자 권한으로 실행 → Install → 재부팅)
2. 작업표시줄 🔊 → 출력 장치 **CABLE Input**
3. zip 압축 풀고 **3DSound.exe** → 입력 **CABLE Output**, 출력 **내 헤드폰** → ▶ 시작

### 🆕 v1.10 — 저음 제대로
- 🔉 **넓은 저음**: 좌우로 넓게 퍼진 저음이 3~4dB 작게 나던 것 수정 — 200Hz 아래는 가상 스피커를 거치지 않고 귀로 바로
- 🐛 **저음 보강이 오히려 저음을 깎던 버그 수정**: 측정 HRTF 와 위상이 어긋나서 보강을 올릴수록 깊은 저음이 줄었습니다
  (음악 프리셋 50Hz -8.6dB, 영화관 -12dB) → 이제 슬라이더 값대로 (25% = 저음 +2dB, 50% = +4dB)
- 방 반사음이 낮은 저음을 상쇄하던 것(50Hz -7dB)도 수정
- 배경음악 리듬 보존 0.84 → 0.88 (영화관 0.79 → 0.84). 앱·PC·아이패드 웹 모두
- 저음이 예전보다 확실히 많아졌으니, 많다 싶으면 '저음 보강'을 낮추세요

### 🆕 v1.9 — 3D 를 켜도 원음과 같은 크기 · 설정 자동 업데이트
- 🔊 **음량 맞춤**: 헤드폰 보정을 켜면 보정 EQ 가 미리 낮춘 볼륨 때문에 3D 소리가 원음보다 작았습니다
  (Bose QC 2023: -3.6dB → 켰다 껐다 비교하면 3D 쪽이 밋밋하게 들림) → 최대 3.5dB 되돌려서 -0.3dB 로.
  최고점 -1dBFS 로 마스터링된 음원에서도 리미터가 거의 안 걸림 (잃는 음량 0.0dB)
- ⚙️ **v1.8 개선이 저장된 설정에도 자동 적용**: 예전 프리셋 3D 강도(85%·95%·65%)를 그대로 쓰고 있었다면
  자동으로 100%·100%·85% 로 (직접 바꾼 값은 그대로)
- 앱·PC·아이패드 웹 모두

### 🆕 v1.8 — 배경음악이 뭉개지던 문제 수정
- 🎵 **잔향 정리**: 긴 잔향의 저음 꼬리(300Hz 아래)를 빼고 양을 60% 로 → 킥·베이스·리듬이 또렷하게.
  배경음악 리듬 보존(1 = 원음) 0.71 → 0.84 (영화관 0.59 → 0.79), 저음 대역 0.50 → 0.95. 머리 바깥 느낌·넓이는 그대로
- 🎤 **가운데 소리 간섭 제거**: 가운데 소리가 세 가상 스피커에서 동시에 나와 2kHz 가 -6.7dB 파이고 250Hz 가 부풀던
  "탁한" 음색 수정 → 가운데 소리 대역 요철 3.0 → 1.3dB
- 프리셋 3D 강도 100% (원음을 섞을 때 생기는 빗살 간섭 제거, 보컬/팟캐스트는 85%)
- 앱·PC·아이패드 웹 모두

### 🆕 v1.7 — 위·아래 스피커 추가 · 3D 강조
- ▲ **천장 스피커 4개**: 앞 2개(±45°, 위 45°) + 뒤 2개(±135°, 위 45°) — 극장 7.1.4 배치처럼 머리 위 앞뒤를 모두 채움
- ▼ **바닥 스피커 2개** (새로): 배경음 일부를 아래쪽에서 (±45°, 아래 30°) → 위·아래·옆·뒤 전부 감싸는 소리
- 배치도에서 ▲/▼를 끌어 옮기기: 돌리면 방향, 머리 쪽으로 끌면 더 높이, 실선 원 바깥으로 끌면 아래.
  끄는 동안 왼쪽 위에 정확한 각도 표시. 세부 슬라이더는 "천장·바닥 스피커 위치 세부 조절"에
- ✨ **3D 강조** (기본 30%): 뒤는 더 뒤처럼, 위·아래는 더 위·아래처럼 — 귓바퀴 주파수 단서를 키움.
  앞(보컬) 음색은 거의 그대로 (30% 에서 최대 0.7dB). 게임 프리셋은 80%
- 천장·바닥·강조를 모두 0 으로 하면 v1.6 과 완전히 같은 소리
- 앱·PC·아이패드 웹 모두

### 🆕 v1.6 — 천장 스피커 자유 배치 · 보컬 음색 수정
- ▲ **천장 스피커를 원하는 곳에**: 스피커 배치도에서 ▲를 끌어 옮기세요. 돌리면 앞쪽 위·머리 옆 위·뒤쪽 위로,
  머리 쪽으로 끌면 더 높이(30°~85°) 갑니다. 슬라이더로도 조절 (앱·PC·아이패드 웹 모두)
- 🎤 **가운데 목소리가 날카롭게(높게) 들리던 현상 수정**: 앞 스피커를 위로 올리면(영화관 프리셋 등) 높이 단서가
  7~8.5kHz 를 좁게 최대 +8dB 키워 보컬이 밝고 높게 들렸습니다 → 넓은 경향만 쓰도록(1옥타브 평활, ±6dB) 고침.
  영화관·콘서트홀 프리셋의 앞 스피커 높이도 낮춤 (10°→5°, 5°→0°)
- 실제 음정(키)은 엔진이 바꾸지 않습니다 (440Hz 를 넣으면 440.00Hz 로 나오는 것 확인)
