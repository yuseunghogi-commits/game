## 🎧 3D 사운드 — 유튜브·게임 소리를 헤드폰용 3D 입체 음향으로

아래 **Assets** 에서 기기에 맞는 파일 **하나만** 받으면 됩니다. 폰은 다른 앱 설치가 필요 없어요.

| 받을 것 | 기기 |
|---|---|
| **3DSound-Android.apk** | 안드로이드 폰 (Android 8 이상 · 강력 3D 모드 10 이상 · 앱 안에서 권한 받기 11 이상) |
| **웹 앱** [yuseunghogi-commits.github.io/game](https://yuseunghogi-commits.github.io/game/) | PC 크롬·엣지 (유튜브 등 브라우저 탭 소리, 설치 없음) · 아이패드 (저장된 음악·영상) |
| **3DSound-Windows.zip** | Windows — 게임 등 PC 의 모든 소리 (무료 [VB-CABLE](https://vb-audio.com/Cable/) 필요) |
| 3DSound-Mac-Linux.jar | Mac / Linux (Java 17 이상, BlackHole 2ch) |

### 📱 안드로이드
1. APK 설치 — **v1.x 를 쓰고 있었다면 이번 한 번만 앱을 지우고 설치하세요** (예전 빌드는 매번 다른 서명 키로 만들어져
   덮어쓰기가 안 됐습니다. 지우면 설정이 초기화되니 프리셋은 다시 골라 주세요)
2. 앱 → **🔑 강력 모드 권한 받기** → 안내대로 (처음 1번, PC·Shizuku 필요 없음)
   - 개발자 옵션 → **무선 디버깅** 켜기 → **페어링 코드로 기기 페어링** → 위에 뜨는 '3D 사운드' 알림에 **6자리 입력**
3. **강력 3D 모드** 선택 → **3D 음향 켜기** → 소리 공유 창에서 **시작**
4. 다음부터는 새 버전이 나오면 앱이 알려 주고 바로 설치합니다 (설정·권한 유지)

### 💻 PC
- **브라우저 소리(유튜브·넷플릭스 웹 등)**: 크롬·엣지에서 [웹 앱](https://yuseunghogi-commits.github.io/game/) → **[다른 탭 소리]** → 유튜브 탭 선택 → '탭 오디오도 공유' (설치 없음)
- **게임 등 모든 PC 소리**: VB-CABLE 설치 (관리자 권한으로 실행 → Install → 재부팅) → 작업표시줄 🔊 출력 **CABLE Input** →
  zip 풀고 **3DSound.exe** → 입력 **CABLE Output**, 출력 **내 헤드폰** → ▶ 시작. 켤 때 새 버전을 확인해서 자동으로 업데이트합니다

### 🆕 v2.3 — 3D 느낌 되살리기 · 음색 보정 슬라이더
- 🎧 v2.1 에서 "필터 낀" 소리를 없애려고 더미헤드 귀 굴곡을 다 폈더니, 바로 그 굴곡이 소리를 **앞에서·머리 밖에서** 들리게
  하는 단서라서 앞 소리(대사·노래)가 머리 안쪽으로 들어와 3D 느낌이 약해졌습니다.
- 🎚 **음색 보정** 슬라이더 (0~100%, 기본 30%): 낮추면 3D 느낌이 강하고, 높이면 원음처럼 깨끗합니다
  (0% = v2.0 의 3D 느낌, 100% = v2.1 의 음색). 움직이면 바로 바뀌고, 프리셋을 바꿔도 그대로입니다.
- 기본 30%: 정면 귀 단서(평균 굴곡) v2.1 2.3dB → 3.5dB 로 되살림 (v2.0 4.2dB 의 80% 이상),
  "필터 낀" 느낌의 원인이던 6~8kHz 골짜기는 v2.0 -9.2dB → -6.1dB (Bose 보정 기준)
- 배경음악 크기 수정(부드러운 헤드폰 보정, 배경음악이 대사보다 +1.1dB)은 그대로. 앱·PC·웹 모두

### 🆕 v2.1 — "필터 낀" 소리 · 작게 들리던 배경음악 수정
- 🎧 **헤드폰 보정을 부드럽게**: 측정대로 다 보정하면 (Bose QC 2023: 105Hz 아래 저음 -4.6dB, 6.3kHz 좁은 홈 -5.7dB)
  음악의 저음이 빠지고 고음이 패여서, 배경음악이 대사보다 작게(-0.3dB) 들렸습니다.
  이제 저음을 깎는 보정은 35%, 좁은 고음 보정은 30% 만 → 배경음악이 대사보다 +1.1dB (원래 믹스처럼)
- 🎚 **더미헤드 귀 음색 보정**: 측정용 더미헤드 귀 모양 때문에 정면 소리가 3~5kHz 들뜨고 6~8kHz 패여서
  필터를 거친 것처럼 들리던 것을 70% 폈습니다. 모든 방향에 같은 곡선이라 3D 위치감은 그대로이고,
  대사·노래(가운데 스피커)는 한 번 더 → Bose 보정 기준 6~8kHz 구멍 -9.2dB → -4.0dB, 가운데 소리 굴곡 평균 5.2 → 2.3dB
- 측정: 좌우 위치·공간감·음량은 변화 없음, 가운데 소리 대역 요철 1.5 → 1.2dB. 앱·PC·웹 모두 (웹은 열면 자동 적용)

- 배치도에서 ▲/▼를 끌어 옮기기: 돌리면 방향, 머리 쪽으로 끌면 더 높이, 실선 원 바깥으로 끌면 아래.

### 🆕 v1.6 — 천장 스피커 자유 배치 · 보컬 음색 수정
- ▲ **천장 스피커를 원하는 곳에**: 스피커 배치도에서 ▲를 끌어 옮기세요. 돌리면 앞쪽 위·머리 옆 위·뒤쪽 위로,
  머리 쪽으로 끌면 더 높이(30°~85°) 갑니다. 슬라이더로도 조절 (앱·PC·아이패드 웹 모두)
- 🎤 **가운데 목소리가 날카롭게(높게) 들리던 현상 수정**: 앞 스피커를 위로 올리면(영화관 프리셋 등) 높이 단서가
  7~8.5kHz 를 좁게 최대 +8dB 키워 보컬이 밝고 높게 들렸습니다 → 넓은 경향만 쓰도록(1옥타브 평활, ±6dB) 고침.
