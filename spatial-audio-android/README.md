# 3D 사운드 (안드로이드)

유튜브·넷플릭스·브라우저·음악앱 등 **폰에서 나오는 소리를 헤드폰용 3D 입체 음향으로 바꿔 주는** 안드로이드 앱입니다.
루팅 없이 동작하며, 화면을 꺼도 백그라운드에서 계속 적용됩니다.

## 기능

| 기능 | 설명 |
|---|---|
| 3D 서라운드 | 안드로이드 `Virtualizer`를 **바이노럴(HRTF) 모드로 강제**해서 헤드폰 전용 가상 서라운드 적용 |
| 공간감 EQ | 저역(바닥감)·중고역(정위감)·초고역(공기감)을 살리는 V자 커브로 소리가 넓게 퍼지게 함 |
| 저음 보강 | `BassBoost` |
| 잔향 | 방/홀 크기 잔향 (세션을 알려주는 음악앱에서만 동작) |
| 프리셋 | 음악 / 영화관 / 콘서트홀 / 게임 / 보컬 / 사용자 설정 |
| 헤드폰 자동 감지 | 유선·블루투스·USB·LE 오디오 헤드폰 연결 시에만 켜지게 할 수 있음 |
| 빠른 설정 타일 | 상단 알림창에서 한 번에 켜기/끄기 |
| 3D 테스트 사운드 | 머리 주위를 도는 바이노럴 테스트음 |

## 동작 원리

- **모든 앱에 적용 (기본)**: 효과를 오디오 세션 0(기기 전체 출력 믹스)에 붙입니다.
  유튜브처럼 오디오 세션을 공개하지 않는 앱에도 적용되는 유일한 비루팅 방법입니다.
- **앱별 세션**: 스포티파이·삼성뮤직·Poweramp 등은 재생 시 오디오 세션을 방송(broadcast)하는데,
  이를 받아 해당 세션에도 효과(특히 잔향)를 붙입니다. 전체 출력에 이미 3D가 걸려 있으면
  이중 처리를 막기 위해 앱별 세션에는 잔향만 추가합니다.
- 다른 이퀄라이저 앱이 제어권을 가져가면 5초마다 확인해서 다시 연결합니다.

## 설치 방법

### 방법 1: GitHub Actions에서 APK 받기 (PC 불필요)
1. 이 저장소의 **Actions → "Build 3D Sound APK"** 에서 최신 실행을 엽니다.
2. 하단 **Artifacts → `3d-sound-apk`** 를 내려받아 압축을 풉니다.
3. 폰으로 APK를 옮겨 설치합니다 (설정에서 "출처를 알 수 없는 앱 설치" 허용 필요).

### 방법 2: 안드로이드 스튜디오
1. `spatial-audio-android` 폴더를 Android Studio로 엽니다.
2. 폰에서 **개발자 옵션 → USB 디버깅**을 켜고 USB로 연결합니다.
3. ▶ Run 을 누르면 폰에 설치·실행됩니다.

명령줄: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`
(`adb install app-release.apk` 로 설치)

## 사용법

1. 앱 실행 → 알림 권한 허용
2. 헤드폰/이어폰 연결
3. **3D 음향 켜기** 스위치 ON → 프리셋 선택
4. 유튜브 등을 재생. 슬라이더로 강도 조절
5. `🎧 3D 테스트 사운드` 로 헤드폰 좌우/앞뒤 확인

## 주의 / 한계

- 요구 사항: **Android 8.0 (API 26) 이상**
- 세션 0 전체 효과는 안드로이드에서 공식적으로 *deprecated* 상태라 **일부 기기(제조사 펌웨어)에서는 막혀 있을 수 있습니다.**
  이 경우 앱 상태창에 경고가 뜨며, 세션을 알려주는 음악앱에서만 동작합니다.
- 실제 3D 처리(`Virtualizer`) 품질은 폰 제조사의 오디오 DSP 구현에 따라 다릅니다.
- 삼성 Dolby Atmos, 기기 내장 "공간 음향", Wavelet 같은 다른 효과 앱과 동시에 켜면 충돌하거나 소리가 뭉개질 수 있으니 하나만 쓰는 것을 권장합니다.
- 일부 기기는 배터리 최적화로 서비스를 종료할 수 있습니다 → 설정에서 이 앱의 배터리 사용을 "제한 없음"으로 바꾸세요.

## 코드 구조

```
app/src/main/java/com/spatialsound/app/
├── MainActivity.kt         화면 (스위치·프리셋·슬라이더·상태)
├── SpatialAudioService.kt  포그라운드 서비스: 세션 0 + 앱별 세션 관리, 헤드폰 감지, 제어권 감시
├── SpatialEngine.kt        세션 하나에 붙는 효과 체인 (Virtualizer/BassBoost/Equalizer/PresetReverb)
├── SpatialSettings.kt      설정 저장/불러오기, 프리셋 정의
├── SpatialTileService.kt   빠른 설정 타일
├── TestSound.kt            바이노럴 회전 테스트음 생성
└── EngineState.kt          서비스 → 화면 상태 전달
```
